# AgentCall Community

Welcome to the AgentCall community! We're building the universal communication layer between AI systems and humans.

## Where We Are

- **GitHub:** [github.com/patil-shubham-dev/AgentCall](https://github.com/patil-shubham-dev/AgentCall)
- **Issues:** Bug reports and feature requests
- **Discussions:** Questions, ideas, and general chat
- **Pull Requests:** Code contributions

## How to Participate

### Users

- Star the repository to show support
- Try the Android app and report bugs
- Suggest improvements via GitHub Issues

### Developers

- Read [CONTRIBUTING.md](./CONTRIBUTING.md) to get started
- Check [DEVELOPMENT_GUIDE.md](./DEVELOPMENT_GUIDE.md) for setup
- Browse [good first issues](https://github.com/patil-shubham-dev/AgentCall/labels/good%20first%20issue)
- Join discussions about architecture and features

### Integrators

- Read [API_SPEC.md](./API_SPEC.md) to integrate an AI provider
- Check [ROADMAP.md](./ROADMAP.md) for upcoming API changes
- Open an issue for integration support

## Community Guidelines

1. **Be respectful** — Everyone is welcome regardless of experience level
2. **Stay on topic** — Keep discussions relevant to AgentCall
3. **Help others** — If you know the answer, share it
4. **Follow the Code of Conduct** — See [CODE_OF_CONDUCT.md](./CODE_OF_CONDUCT.md)

## Project Values

- **AI Agnostic** — Works with any AI provider
- **Open Source** — Always free and transparent
- **Privacy First** — Your data belongs to you
- **Communication First** — AgentCall transports, AI thinks

## Governance

AgentCall is maintained by [@patil-shubham-dev](https://github.com/patil-shubham-dev). Major architectural decisions are documented as Architecture Decision Records in [docs/adr/](./docs/adr/).

## Let's Build Together

The best way to predict the future is to build it. Join us in creating the universal communication layer for AI.
